# DT Getai Grotesk Display Black

Self-hosted display font for page headings (`h1`) and the 404 graphic. The full supplied
`DTGetaiGroteskDisplay-Black.ttf` was converted to WOFF2 with FontTools 4.67.0
and Brotli compression, without subsetting or changing glyphs or font metrics.
Only the web-ready WOFF2 is kept, following the Inter and Commit Mono directories.
